# AWS Static Website Project

## Overview

This project demonstrates how to host a static portfolio website on AWS using Amazon S3, CloudFront, Route 53 and AWS Certificate Manager (ACM) for HTTPS.

The website is deployed with HTTPS, delivered through Amazon CloudFront, and connected to a custom domain using Route 53.

## AWS Services Used

- Amazon S3
- Amazon CloudFront
- Amazon Route 53
- AWS Certificate Manager (ACM)

## Skills Demonstrated

- Static website hosting
- DNS management
- Content Delivery Networks (CDN)
- HTTPS and SSL certificates
- Custom domain configuration
- Git and GitHub version control
